# Buscar un lugar / Lekua bilatu

En Trayectorias (básica y Premium), pulsa **Buscar lugar**, escribe un pueblo o una calle y pulsa **Buscar** o Intro. Añade el municipio para distinguir calles con el mismo nombre. Elige un resultado: el mapa se desplaza allí, detiene la reproducción y sale del modo de añadir puntos. Las trazadas y señales existentes se conservan. Escape o × cierran el buscador.

Ibilbideetan (oinarrizkoa eta Premium), sakatu **Lekua bilatu**, idatzi herria edo kalea eta sakatu **Bilatu** edo Intro. Gehitu udalerria izen bereko kaleak bereizteko. Hautatu emaitza: mapa lekura mugitzen da; erreprodukzioa eta puntuak gehitzeko modua gelditzen dira. Aurretik prestatutako trazatuak eta seinaleak mantentzen dira. Escape edo × botoiak bilatzailea ixten du.

Requiere Internet / Internet behar da. Cobertura: España. CartoCiudad / IGN-CNIG, CC BY 4.0 https://www.scne.es/productos.html#CartoCiudad . Las consultas se envían directamente a CartoCiudad únicamente al buscar o seleccionar; no se envían proyectos ni datos de alumnos. No se buscan direcciones mientras se escribe. Error de conexión: permite reintentar y el mapa existente sigue disponible.
